# Image Gallery Unsplash API

## Overview

This is a dynamic image gallery built with JavaScript that fetches images from the Unsplash API.
Users can search for images using keywords and navigate through paginated results.

## Features

- **Image Fetching from Unsplash API** – Displays high-quality images.
- **Search Functionality** – Users can search images by keyword.
- **Pagination Support** – Browse through multiple pages of results.
- **Responsive Design** – Works seamlessly across devices.
- **Loading Indicator** – Displays while fetching images.

## Technologies Used

- **HTML** – Structure of the gallery.
- **CSS** – Styling for a clean, responsive layout.
- **JavaScript (ES6)** – Handles API requests and user interactions.
- **Unsplash API** – Provides high-quality images dynamically.

## Installation & Usage

1. Clone the repository:
   ```sh
   git clone https://github.com/Elena-MyOne/image-gallery-js.git
   ```
2. Navigate to the project directory:
   ```sh
   cd image-gallery-js
   ```
3. Open `index.html` in a web browser.
4. Replace `YOUR_ACCESS_KEY` in the API call with your Unsplash API key.

## How to Use

- Enter a keyword in the search bar and press **Enter** to fetch images.
- Scroll through paginated results using the **Next** and **Previous** buttons.
- Click an image for a larger preview (if implemented).
